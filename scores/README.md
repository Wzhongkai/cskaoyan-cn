# 历年分数线数据

每个研究所维护一个独立的 Markdown 文件，首页会自动读取并汇总。文件名由 `site-config.js` 中的 `scoreFile` 指定。

新增数据文件时可以参考 `example.md`。该文件没有配置给任何研究所，仅用于展示填写格式，不会被首页解析。

## 表格格式

保持表头名称不变，直接填写预留的近三年数据：

```md
| 年份 | 类型 | 专业 | 专业课代码 | 政治 | 英语 | 数学 | 专业课 | 总分线 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2026 | 学硕 |  |  |  |  |  |  |  |
| 2026 | 专硕 |  |  |  |  |  |  |  |
| 2025 | 学硕 |  |  |  |  |  |  |  |
| 2025 | 专硕 |  |  |  |  |  |  |  |
| 2024 | 学硕 |  |  |  |  |  |  |  |
| 2024 | 专硕 |  |  |  |  |  |  |  |
```

- `类型`填写`学硕`或`专硕`。
- `专业课代码`填写`408`、`866`等考试科目代码。
- `政治`、`英语`、`数学`、`专业课`分别填写对应的单科线。
- 每个“年份 + 类型 + 专业”对应一行；同一年可以增加多行填写不同专业。
- 年份行可以自由增加或删除，不要求每年都同时填写学硕和专硕。
- 首页按当前年份自动只显示最近三年。当前日期为 2026 年时，展示 2024、2025、2026 年；旧数据可以继续保留，不需要手动删除。
- 新增年份后不需要修改 JavaScript 或 HTML，进入最近三年范围后会自动显示。
- 首页支持按研究所、年份、专业课代码和学硕/专硕类型组合筛选。
